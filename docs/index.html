安装说明

几步即可开始使用

Windows

  1. 双击下载的 SciPlot-Setup-1.0.0.exe，按中文安装向导完成安装；
  2. 桌面或开始菜单找到「SciPlot 科学数据分析与绘图」启动；
  3. 导入数据（CSV / TXT / Excel），即可开始绘图与分析。

macOS

  1. 双击 SciPlot-macOS-arm64.dmg 挂载，把 SciPlot 拖入「应用程序」；
  2. 首次打开若提示「无法验证开发者」，在终端执行一次：
    xattr -cr /Applications/SciPlot.app
  3. 之后正常双击打开。
说明：macOS 版为未签名构建，系统安全策略（Gatekeeper）会拦截首次运行，上述 xattr 命令可解除限制，属正常现象。
